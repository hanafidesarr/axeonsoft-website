# Axeonsoft - Modern Web Platform & Digital Solutions

Website resmi dan showcase interaktif **Axeonsoft** (Software House & Digital Solutions) dengan integrasi divisi game **Catbox Studio**.

Dibangun menggunakan stack modern:
- **Vite 6** + **React 18**
- **Tailwind CSS 3** (Custom Dark Tech Theme dengan Primary Color Gold `#fec003`)
- **Lucide React & Custom Brand SVG Icons**
- **Bilingual i18n Engine** (English default & Bahasa Indonesia)

---

## 🚀 Cara Menjalankan (Quick Start)

Untuk menjalankan server pengembangan lokal:

```bash
npm run dev
```

Server lokal akan langsung berjalan di:
👉 **`http://localhost:3000/`** (atau port default Vite)

### Perintah Lainnya:
```bash
# Build untuk produksi
npm run build

# Preview build produksi secara lokal
npm run preview
```
